# React Web Dashboard Subsystem

## Overview
Control-room command center for municipal administrators, distribution engineers, and utility supervisors.

## Features (Phase 6 Roadmap)
1. **Interactive GIS Map:** Real-time marker clusters of utility poles color-coded by risk index.
2. **Live Telemetry Stream:** WebSocket feeds displaying real-time current, tilt, and humidity graphs via Recharts.
3. **Incident Ticket Management:** Workflow for assigning field tickets, tracking resolution times, and reviewing audit logs.
4. **AI Vision & RAG Console:** Manual image upload for YOLO inspection and knowledge base interrogation.

## Technology Stack
* React 18
* Tailwind CSS
* Vite
* Leaflet / React-Leaflet
* Recharts & Lucide Icons
